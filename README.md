# 📦 Controle de Materiais

> Sistema desenvolvido para o gerenciamento de estoque, facilitando o controle de entrada, saída e armazenamento de materiais e insumos.

O projeto **Controle de Materiais** tem como objetivo digitalizar e automatizar a gestão de inventário. Com ele, é possível registrar novos produtos, monitorar quantidades disponíveis e manter um histórico preciso de movimentações, evitando faltas ou excessos no estoque.

---

## ✨ Funcionalidades

- [x] Cadastro, edição e exclusão de materiais/produtos
- [x] Registro de entrada (compras/recebimentos) e saída (consumo/vendas)
- [x] Consulta de saldo atual de estoque em tempo real
- [x] Alertas para materiais com estoque abaixo do limite mínimo *(opcional)*
- [x] Geração de relatórios de movimentação *(opcional)*
